## 🚀 Hugging Face Spaces Deployment

1. Set your Space SDK to **Docker**.
2. In your Space **Settings** $\to$ **Variables and secrets**:
   - Add Secret: `GROQ_API_KEY` with your key.
   - Add Variable: `GROQ_MODEL` = `openai/gpt-oss-120b`.
3. Your Space will build and run on port `7860` automatically!
